# Xencelabs Quick Keys Profiles

Repositório contendo arquivos de configuração (`.pcfg`) para o macro pad Xencelabs Quick Keys, com foco em produtividade para desenvolvimento de software e atalhos otimizados para jogos no Windows.

## ⚙️ Como Importar

* Abra o aplicativo **Xencelabs**.
* Selecione o dispositivo **Quick Keys**.
* Clique no ícone de engrenagem (Configurações) no canto superior direito.
* Selecione **Importar** e escolha o arquivo `.pcfg` desejado na sua máquina.
